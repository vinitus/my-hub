# 국내 날씨 지역 목록

`korean-weather-regions.json`은 기상청의 **기상청41_단기예보 조회서비스_오픈API활용가이드_격자_위경도(2610).xlsx**에서
국내 시도/시군구/읍면동 대표 위경도를 추출한 3,837개 항목이다(읍면동 3,565개 포함).
표시 명칭은 원본의 현행 행정구역 명칭을 유지한다. 약칭/이전 명칭은 검색 모듈의 별칭으로 처리한다.
동일 이름의 읍면동도 행정구역 코드와 상위 시도·시군구로 구분한다.

- 제공기관: 기상청
- 출처: https://www.data.go.kr/data/15084084/openapi.do
- 원본 ZIP: https://www.data.go.kr/cmm/cmm/fileDownload.do?atchFileId=FILE_000000007732424&fileDetailSn=1
- 원본 XLSX SHA-256: `76c1bdae7b5299c81e0582b42d1507775183603072f141ce8d96e6054851b391`
- 이용허락: 공공누리 제1유형(출처표시). 지역 선택 화면에도 기상청 출처 링크를 표시한다.

Python 표준 라이브러리만 사용하는 변환 스크립트로 다시 생성할 수 있다.
원본 XLSX는 수정하지 않으며 ZIP/XLSX를 배포물에 포함하지 않는다.

```bash
python scripts/import-korean-weather-regions.py <다운로드한-공식-활용가이드.zip>
```

국내(`kor`) 행의 시도·시군구·읍면동명과 행정구역 코드,
N/O열의 경도/위도를 사용한다. 좌표가 0인 이어도 격자 전용 항목은 제외한다.
새 원본으로 갱신할 때 스크립트의 다운로드 주소와 이 문서도 함께 수정하고 `pnpm test:weather`를 실행한다.
실제 행정구역 개편이 있으므로 시도 개수를 고정된 숫자로 가정하지 않는다.
읍면동은 원본의 행정구역 목록 기준이며 모든 법정동이나 도로명 주소를 포함하지는 않는다.
