# React Best Practices

1. Write pure, deterministic React components.
2. Never mutate props or state directly.
3. Follow the Rules of Hooks.
4. Use stable, unique keys in lists.
5. Keep state minimal; derive values when possible.
6. Avoid unnecessary useEffect calls.
7. Implement proper Effect cleanup.
8. Prefer event handlers for user interactions.
9. Prefer component composition.
10. Extract reusable logic into custom Hooks.
11. Avoid premature memoization.
12. Use semantic HTML and accessible labels.
13. Enable React Strict Mode and Hooks linting.
14. Avoid unnecessary abstractions.
15. Use clear TypeScript prop types.
