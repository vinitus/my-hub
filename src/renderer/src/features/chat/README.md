# 채팅 화면

앱의 첫 화면이다. 현재는 대화 입력과 로컬 기록을 제공한다.
실제 AI 응답, 캘린더 추가, 메모 저장 요청은 아직 실행하지 않는다.
현재 상태는 **AI 연결 필요 · 추가 작업 필요**이며 AI 연동은 보류한다.
예시 카드는 입력창에 문구만 채운다.

- `chat-workspace.tsx`: 대화 목록 전환, 새 대화/삭제, 메시지 전송, 입력창,
  로컬 저장과 오류 표시. `send()`가 이후 AI 요청을 연결할 지점이다.
- `chat-storage.ts`: 버전이 있는 대화 스키마, 초기 로드, 기록 제한과 제목 생성.
  실제 모델 연결 시 `MessageSchema`에 assistant/tool 역할을 확장한다.

`localStorage`의 `my-hub:chat:v1`에 대화와 입력 초안을 저장한다.
개발 서버의 호스트/포트가 달라지면 브라우저 origin도 바뀌므로 기록은 공유되지 않는다.
현재 기록은 Electron 앱의 사용자 프로필에 보관되는 UI 데이터이며 `.md` 메모나
`calendar.json`에 저장하지 않는다. AI 연동 단계에서 main/preload를 통한 대화 저장으로
옮길 수 있다. API 키는 이 저장소에 넣지 않는다.

최대 30개 대화, 대화당 200개 메시지, 메시지당 8,000자를 허용한다.
한도에 도달해도 기존 대화를 자동 삭제하지 않는다. 삭제는 확인 버튼을 한 번 더 누른다.
손상된 기록은 보존하고 오류를 알리며, 저장 용량 부족도 화면에 표시한다.

`App.tsx`는 화면 전환 후에도 채팅을 마운트해 입력 상태를 유지한다.
메모 단축키는 채팅 화면에서 비활성화되며, 기존 메모 자동 저장은 계속 동작한다.
Enter로 전송, Shift+Enter로 줄바꿈하며 한국어 IME 조합 중 Enter는 전송하지 않는다.

AI 연결 시 사용자 입력을 main에 전달하고 모델의 도구 요청을 검증한 뒤 기존
메모/캘린더 저장 API로 연결한다. AI의 텍스트 답변과 실제 저장 성공 결과를 구분해 표시한다.
