# 바로가기

프로그램·폴더·웹사이트를 등록하고 카드 클릭으로 여는 화면이다.
Windows 프로그램은 `.exe`와 기존 `.lnk` 바로가기를 지원한다.
실행 인수나 작업 폴더 설정이 필요하면 해당 설정이 있는 `.lnk`를 등록한다.
폴더는 파일 탐색기, 웹사이트는 기본 브라우저로 연다.
등록/수정 시에는 실행하지 않으며, 삭제는 목록에서만 제거한다.

화면에 `.exe`/`.lnk`, 폴더 또는 브라우저의 웹 링크를 끌어 놓으면
종류·이름·대상을 판별하여 등록창을 연다. 한 번에 하나씩 등록하며 저장 전에는 목록을 변경하지 않는다.
일반 문서와 여러 항목을 동시에 놓는 경우는 안내 후 거부한다.
`drop-input.ts`는 drop 이벤트에서 File/URI를 동기적으로 읽고,
preload의 `webUtils.getPathForFile()`이 실제 파일 경로를 main으로 전달한다.
`File.path`를 사용하거나 File 객체 자체를 IPC로 보내지 않는다.
웹 링크는 `text/uri-list`를 우선하며 URL 텍스트도 허용한다.

## 구조

| 파일 | 역할 |
| --- | --- |
| `shortcut-workspace.tsx` | 카드 목록, 검색/필터, 편집창, 실행 결과 안내 |
| `shortcut-sheet.tsx` | 등록/수정, 대상 선택, 삭제 확인 |
| `shortcut-store.ts` | IPC 호출과 상태, 중복 요청 억제, 실패 시 기존 목록 유지 |
| `../../../../shared/shortcuts.ts` | 공통 타입, 입력 스키마, URL 허용 규칙 |
| `../../../../main/shortcut-target.ts` | 절대 경로, 파일 존재, 프로그램/폴더 구분 검사 |
| `../../../../main/shortcut-repository.ts` | JSON 저장, 충돌 확인, 등록 ID로 대상 조회 |
| `../../../../main/shortcuts.ts` | IPC 발신자 확인, OS 선택창, 실제 열기 요청 |

`window.api.shortcuts`를 거쳐 main에서 Electron `shell.openPath`/`openExternal`을 호출한다.
명령 문자열이나 셸을 조합해서 실행하지 않는다. 실행 IPC는 대상 경로가 아니라 등록 ID와
현재 목록의 revision만 받는다. 저장 시와 실행 직전에 경로를 검사한다.
웹사이트는 로그인 정보 없는 HTTP/HTTPS만 허용한다.

저장 파일은 `app.getPath("userData")/shortcuts.json`이다.
UTF-8 JSON이며 최대 500개, 1MB를 허용한다. 임시 파일에 쓴 뒤 교체하며 앱 내 쓰기는 직렬화한다.
파일 내용의 SHA-256을 revision으로 사용하고, 외부 변경이 발견되면 새로고침을 안내한다.
편집창을 연 시점의 revision을 유지해 오래된 편집이 최신 목록을 덮어쓰지 않게 한다.
손상되거나 지원하지 않는 버전의 파일은 자동 초기화하지 않는다.

OS가 열기 요청을 수락했다고 해서 프로그램 내부의 시작 완료까지 확인한 것은 아니다.
화면은 이를 구분해 “열기 요청을 보냈습니다”로 안내한다.
아이콘은 `ShortcutIcon`이 등록 ID/revision으로 요청한다. `shortcut-icons.ts`에서
프로그램·폴더는 `app.getFileIcon()`으로 OS 아이콘을 가져온다.
Windows `.lnk`는 `shell.readShortcutLink()`로 해석하고 별도 아이콘 경로 → 실행 대상 →
원래 `.lnk` 순서로 아이콘을 읽는다. 경로의 환경 변수를 확장하며 빈 이미지나 오류 시 다음 후보를 사용한다.
실제 실행은 `.lnk` 그대로 유지해 기존 인수와 작업 폴더를 보존한다.
웹사이트는 해당 origin의 `/favicon.ico`만 요청하며 제3자 favicon 서비스는 사용하지 않는다.
홈페이지 HTML을 파싱하거나 리다이렉트를 따라가지 않으므로 일부 사이트는 기본 아이콘으로 표시된다.
최대 256KB, 4초 제한, 6개 동시 요청을 적용한다. 비트맵만 data URL로 전달하며
아이콘은 JSON에 저장하지 않고 최대 512개를 5분간 메모리에 캐시한다.
파일 아이콘은 바로가기·실행 대상·별도 아이콘의 수정 시각이나 크기가 바뀌면 다시 가져온다. 실패·빈 이미지·디코딩 오류 시
종류별 Lucide 아이콘으로 대체하며 바로가기 실행에는 영향을 주지 않는다.

## 검증

`pnpm test:shortcuts`로 파일 저장/충돌/손상 보존, 실행 대상 검사,
IPC 발신자와 등록 ID 검증, OS 오류 전달, 선택 취소와 중복 실행을 검사한다.
드롭 데이터 해석과 대상 판별, 저장/실행 없는 등록 준비도 검증한다.
테스트의 Electron 경계는 실제 앱이나 브라우저를 실행하지 않는다.

main/preload 변경 후에는 Electron을 완전히 닫고 `pnpm dev`를 다시 실행한다.
