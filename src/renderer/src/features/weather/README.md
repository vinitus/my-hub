# 사이드바 날씨

`AppSidebar` 하단에 표시한다. 첫 사용 시 도시를 검색해서 선택하며 GPS/IP로 위치를 추정하지 않는다.
현재 기온, WMO 날씨 상태, 낮/밤 아이콘, 오늘 최저/최고 기온과 해당 지역의 기준 시각을 표시한다.
체감 기온은 날씨 영역의 툴팁으로 확인한다.

## 구조

- `ui/weather-widget.tsx`: 작은 날씨 카드와 지역 검색 Sheet.
- `lib/weather-condition.ts`: WMO 날씨 코드를 한국어와 아이콘 종류로 변환한다.
- `model/use-weather.ts`: React 상태와 주기적 갱신, 이전/새 지역 응답 분리.
- `../../../../shared/weather.ts`: 공통 API와 지역 좌표 스키마.
- `../../../../main/weather-service.ts`: 고정 API 호출, 데이터 검증, 캐시와 지역 저장.
- `../../../../main/weather.ts`: 현재 창/메인 프레임을 확인하는 제한된 IPC.
- `../../../../main/korean-weather-regions.ts`: 국내 지역 약칭·복합어·동명 지역 검색.
- `../../../../main/data/korean-weather-regions.json`: 기상청 공식 자료에서 추출한 국내 대표 좌표.

국내 검색은 로컬 3,837개 지역 목록을 사용한다. `서울`, `서울시`, `강남구`, `부산 해운대`,
`경기 성남 분당`, `강남구 역삼동`, `제주 애월읍` 등으로 검색하며 인터넷을 사용하지 않는다.
한글 검색에서 결과가 없으면 빈 목록을 반환한다. `역삼동`은 역삼1동·역삼2동처럼 번호가 있는 행정동도 찾는다.
영문 등 다른 검색에서 국내 결과가 없으면 기존 Open-Meteo 지역 검색으로 해외 도시를 찾는다.
시도/시군구/읍면동을 지원하며 동은 행정동 기준이다. 상세 주소 검색은 제공하지 않는다.
동명 지역은 결과의 시도·시군구로 구분한다. 결과는 최대 20개이므로 넓은 검색은 상위 지역부터 표시하고,
특정 동을 찾으려면 시군구를 함께 입력한다. 선택한 읍면동의 대표 좌표를 기존 날씨 API에 전달한다.
가까운 동끼리는 API의 격자에 따라 같은 날씨가 표시될 수 있다.
원본 출처, 추출 규칙과 갱신 명령은 `src/main/data/README.md`를 참고한다.
옛 `광주광역시` 명칭은 해당 5개 구와 소속 동에만 연결하며 통합 시도의 다른 시군으로 확장하지 않는다.

네트워크 요청은 main에서만 하며 renderer에서 URL을 지정하지 않는다.
선택한 지역은 `app.getPath("userData")/weather-settings.json`에 임시 파일 교체 방식으로 저장한다.
지역 설정이 없으면 자동 요청하지 않는다. 날씨는 모델 기반 현재 데이터이며 파일에 저장하지 않는다.
마지막으로 요청한 지역 한 개만 10분간 메모리에 캐시한다. 동일 좌표를 동시에 요청하면 같은 Promise를 사용한다.
사용자가 새로고침을 누르면 캐시를 건너뛰고 다시 요청한다.
실패한 요청은 캐시하지 않는다. 15분마다 갱신하며 숨겨진 창에서는 건너뛴다.
네트워크 복구 시 재시도하고, 창으로 돌아왔을 때 15분 이상 지난 데이터는 다시 조회한다.

갱신 실패 시 같은 지역의 이전 값을 유지하고 이전 정보임을 표시한다.
새 지역 선택 시에는 이전 지역의 기온을 지우고 늦게 도착한 이전 요청을 무시한다.
검색/날씨 요청은 8초 제한이며 응답과 좌표를 검증한다.
시간은 API의 Unix timestamp를 밀리초로 변환하고 API가 반환한 도시 시간대로 표시한다.

## 데이터 출처

[Open-Meteo 날씨 API](https://open-meteo.com/en/docs),
[지역 검색 API](https://open-meteo.com/en/docs/geocoding-api)와 GeoNames 해외 지역 데이터,
[기상청](https://www.data.go.kr/data/15084084/openapi.do)의 국내 지역 좌표 자료다.
카드에 Open-Meteo 출처 링크를 표시한다. 현재는 키 없는 비상업용 API를 사용하며
상업 배포 시 서비스 이용 조건과 요금제를 확인한다. Open-Meteo/GeoNames 데이터는 CC BY 4.0,
기상청 국내 좌표 자료는 공공누리 제1유형(출처표시)이다.

`pnpm test:weather`로 설정 복원, 좌표/응답 검증, API 실패/재시도, 캐시,
IPC 발신자 확인과 지역 별칭 범위를 검사한다.
main/preload가 변경되면 Electron을 완전히 닫고 `pnpm dev`를 다시 실행한다.
